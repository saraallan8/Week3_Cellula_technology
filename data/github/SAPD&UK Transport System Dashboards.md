## 📥 How to View

> 💡 *GitHub cannot render Excel or Power BI files in the browser.*
> **Please download the files to explore the full interactive dashboard.**

| File | Description | Tool Required |
|------|-------------|--------------|
| `Excel/Student_Record_for_Analysis.xlsx` | Student academic records data | Microsoft Excel |
| `PowerBI/SAPD.pbix` | Student Academic Performance Dashboard | [Power BI Desktop (Free)](https://powerbi.microsoft.com/desktop) |
| `PowerBI/exp.pbix` | UK Transport System Dashboard | [Power BI Desktop (Free)](https://powerbi.microsoft.com/desktop) |

----------------------------------

## ✨ Features

### 🎓 Student Academic Performance Dashboard
- 📊 Visual breakdown of student grades and performance trends
- 🗂️ Filterable by subject, semester, and student category
- 📈 KPI cards for pass rates, averages, and top performers

### 🚌 UK Transport System Dashboard
- 🚇 Analysis of UK transport usage and performance metrics
- 📍 Regional breakdown of transport data
- 📉 Trend analysis across transport types

---

## 🛠️ Tools Used

- **Microsoft Excel** — Data cleaning, pivot tables, charts
- **Power BI Desktop** — Interactive visuals and DAX measures
